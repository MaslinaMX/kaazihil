## 📖 Cómo Usar

### Para modificar estilos:

1. Usa la tabla "Dónde está..." en QUICK_REFERENCE.md
2. Abre el archivo correspondiente
3. Busca la clase CSS
4. Realiza tus cambios
5. ¡Listo! Se aplica automáticamente

### Para agregar componentes:

1. Crea `11-nombre-componente.css`
2. Agrega la importación a `style.css`
3. Escribe tu CSS

### Para cambiar colores globales:

1. Abre `01-variables-reset.css`
2. Modifica variable en `:root {}`
3. ¡Todos los estilos se actualizan!
